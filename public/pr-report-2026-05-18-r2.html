概览

本轮针对家长在移动端反馈的两个痛点 「加载慢」 与 「页面切换不顺」，做了一次交互架构与性能的并行重构。所有改动集中在 index.html 与几张大图。

改动均集中在单一文件 + 几张图替换，回滚粒度小。若任一项不合预期，单 commit revert 即可。

① 底栏信息架构重新切分

变化前

  • 底栏：筛选 / 了解我们 / 常见问答 / 咨询报名 — 4 项混杂两种交互
  • 了解我们 / 常见问答 是从屏幕底部弹起的 sheet

变化后

  • 底栏：首页 / 了解我们 / 常见问答 / 咨询报名 — 前 3 真 tab 切换，咨询报名仍是弹窗
  • 「筛选」漏斗按钮挪到首页顶部右侧（紧贴年龄 tab）
  • 了解我们 / 常见问答 成为与瀑布流并列的一级页面（类比小红书首页/市集/消息/我的）
  • 3 个一级页面各自记忆 scrollTop，切回保持原位置

② 首页年龄段「真横滑」4 panel

原来是点击 tab + CSS 过滤；现在是真 4-panel 横滑，类小红书发现/关注/同城。

  • 4 个 panel：全部 / 9-12 / 12-16 / 14-18
  • 手指水平滑动 ≥ 30% 宽度或速度 ≥ 0.5 px/ms 即切换；点击年龄 tab 也可切
  • 切换有 280ms 缓动过渡，边界拖拽带阻尼回弹
  • 每个 panel 独立记忆滚动位置
  • 实现：现有 25 张手写卡片不重写，初始化时按 data-group 克隆分发到对应 panel；克隆卡的视频自动卸 src，避免多倍加载

③ 移动端 MP4 性能

变化前

  • 13 个 MP4 同时设 preload="auto" + autoplay
  • 页面打开 → 浏览器并发拉所有视频，带宽 & 解码都打满

变化后

  • 所有 MP4 改为 data-src + preload="none"，不预加载
  • IntersectionObserver 接管：仅当前 panel + 在视口可见的 MP4 才挂 src 并播放
  • 切 panel 时旧 panel 的 MP4 全部 pause()（保留 src 避免 iOS 重挂首帧黑屏）
  • 滚动节流补 250ms 兜底，避免 IO 漏帧

⑤ 底部弹窗按住下滑收起

  • 筛选 sheet、咨询报名 modal 均支持按住下滑关闭
  • 阈值：位移 > 100 px 或 速度 > 0.5 px/ms 即关闭
  • 仅在 sheet 内部已经滚到顶 (scrollTop = 0) 时识别为关闭手势（否则交给内部滚动）
  • 原「点空白处关闭」「点关闭按钮关闭」均保留
